# Калькулятор
В программе есть меню, которое позволяет выбрать калькулятор -
базовый или со звездочкой.

## Базовый калькулятор (BasicCalculator.java)

В файле `BasicCalculator.java` описан класс базового калькулятора.

### Суть работы
1. Происходит построчный ввод первого числа, операции и второго числа. 
2. Происходит указанная операция над двумя числами. 
3. Выводится результат.

### Технические особенности:
- Если введенная операция не поддерживается, выходит сообщение об ошибке, и
программа завершает работу.
- При делении на ноль выходит сообщение об ошибке, и программа завершает работу.


## Калькулятор со звездочкой (AdvancedCalculator.java)

В файле `AdvancedCalculator.java` описан класс калькулятора со звездочкой.

### Отличия от базового калькулятора:
- Добавлена валидация чисел.
- Добавлены команды отмены `c` и завершения работы `s`. Каждый ввод проверяется
на наличие этих команд.
- Результат, полученный после выполнения операции, становится первым операндом 
для следующей операции.
- При делении на ноль числа и операция сбрасываются, и выходит приглашение ввести
число.
